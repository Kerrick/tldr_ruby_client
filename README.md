# tldr_ruby_client

> [!NOTE]  
> **tldr_ruby_client** is a community port that is not affiliated with [the tldr-pages team](https://github.com/orgs/tldr-pages/people).


## Introduction

**tldr_ruby_client** is a command line client for [tldr pages](https://tldr.sh). It allows you to browse cheatsheets as supplement to `man` pages.

> [!WARNING]  
> **tldr_ruby_client** is currently in an early stage of development. Use at your own risk.

Please join our **announce** mailing list at https://lists.sr.ht/~kerrick/tldr_ruby_client-announce to stay up-to-date on new releases and announcements.


## Compatibility

This project was started because of [CosmoRuby](https://github.com/igravious/cosmoruby/blob/feature/ruby-3.4.7-port/third_party/ruby-wip-3.4.7/README.cosmo), an [actually portable executable](https://justine.lol/ape.html) of [Ruby](https://www.ruby-lang.org) built with [Cosmopolitan Libc](https://github.com/jart/cosmopolitan).
As such, **tldr_ruby_client** is designed to run on [everything Cosmopolitan supports](https://github.com/jart/cosmopolitan?tab=readme-ov-file#support-vector), including:

- GNU/Linux, macOS, Windows, OpenBSD, FreeBSD, and NetBSD; and
- x86_64 (AMD, Intel) and ARM (Apple Silicon, Raspberry Pi).
